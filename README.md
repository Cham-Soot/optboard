# 옵션 행사가 누적표

KOSPI200 옵션의 **행사가별 콜/풋 시세를 매일 한 줄씩 쌓아 두는** 도구입니다.
한국투자증권 오픈API로 장 마감 후 자동 수집하고, 웹 화면에서 마킹·메모를 남기고, 엑셀로 뽑습니다.

```
scripts/setup_env.py     .env 만들기 (메모장 대신 — 확장자 함정 회피)
scripts/master.py        거래소 종목코드 마스터 받기 (앱키 불필요·100건 상한 우회)
scripts/split_memos.py   시세 파일에 섞인 메모를 개인 파일로 분리 (공개 저장소용)
scripts/strikes.py       행사가 진단 — 증권사가 실제로 뭘 주는지 확인
scripts/selftest.py      연결 자가진단 — 앱키 노출 없이 어디까지 되는지 확인
scripts/kis.py           KIS API 최소 클라이언트 (앱키 2개만 있으면 됨)
scripts/collect.py       하루치 수집 — 매일 자동 실행되는 본체
scripts/archive.py       만기 지난 월물 봉인 (json + xlsx 백업)
scripts/calendar_sync.py  한국거래소 개장 달력 받아 캐시 (KIS 국내휴장일조회)
scripts/expiry_notice.py 만기일 계산 — 앱 배너와 GitHub 알림이 같이 씁니다
scripts/backfill.py      과거 되메우기 (자동화 시작 전 구간, 빠진 날)
scripts/build_viewer.py  데이터를 뷰어 HTML에 심어 index.html 생성
viewer_template.html     뷰어 원본 (데이터 자리만 비어 있음)
index.html               공개용 화면 (GitHub에 올라감 — 시세만)
내화면.html              개인용 화면 ← 내 PC에서는 이걸 여세요 (마킹·메모 내장, 안 올라감)
data/2507.json           월물별 데이터 (첨부해 주신 25년 7월물이 들어 있습니다)
data/marks.json          마킹·메모 — 내 PC 에만 (.gitignore 가 막음)
data/calendar.json       거래소 휴장일 캐시 (자동 생성)
data/optcodes.json       월물·행사가별 종목코드 (자동 생성)
archive/                 만기 지난 월물의 봉인본 — 여기가 유일한 원본입니다
config.json              수집 범위 설정
.github/workflows/       매일 자동 실행 (GitHub Actions)
```

## 기록은 사라지지 않습니다

**만기가 지난 월물은 증권사 API로 다시 받을 수 없습니다.** 그래서 아무것도 지우지 않습니다.

| 어디에 | 무엇이 | 언제 |
|---|---|---|
| `data/{월물}.json` | 원본 시세. 지난 월물도 그대로 남음 | 매일 |
| `archive/{월물}.json` | 만기 뒤 확정된 봉인본 (시세만 — 마킹·메모는 내 PC 에서 돌릴 때만 합쳐짐) | 만기 다음 달 첫 실행 |
| `archive/{월물}.xlsx` | 앱 없이 그냥 열어 보는 엑셀 백업 | 위와 같음 |
| `archive/INDEX.md` | 무엇이 언제 봉인됐는지 목록 | 위와 같음 |

화면 파일이 무거워지지 않도록 **`index.html` 에는 최근 3개 월물만 심습니다.**
그보다 오래된 월물도 드롭다운의 **「지난 월물 (보관)」** 에 그대로 뜨고,
고르면 그때 파일을 읽어 옵니다. 인터넷 없이 로컬 파일로 볼 때는
**데이터 불러오기** 로 `archive/{월물}.json` 을 열면 됩니다.

## 1단계 — 한국투자증권 앱키 발급

키움 REST API에는 **국내 선물·옵션 시세가 없습니다**(공식 API 목록이 국내주식·미국주식뿐).
그래서 한국투자증권(KIS)을 씁니다. 매매는 안 하고 시세만 봐도 됩니다. 발급은 무료입니다.

1. **계좌 개설** — 한국투자증권 앱에서 비대면으로. **본인 명의여야 합니다** (가족 명의 불가)
2. **이메일 등록 확인** — 비대면으로 만든 계좌는 이메일이 비어 있는 경우가 있습니다. 미리 등록해 두세요
3. **HTS ID 확인** — ID에 `$` 나 `@` 가 들어 있으면 나중에 API 이용에 제약이 생깁니다. 있으면 미리 변경
4. [KIS Developers](https://apiportal.koreainvestment.com) → 우상단 **API 신청**
   (또는 한국투자증권 홈페이지 → 서비스신청 → Open API → KIS Developers)
5. 인증서 로그인 → 휴대폰 본인확인 → 약관 동의 → **계좌 선택** → 신청
6. 신청 즉시 **앱키(APP KEY)** 와 **앱시크릿(APP SECRET)** 이 발급됩니다 → 이 두 개가 전부입니다

> **이용기간은 신청일로부터 1년입니다.** 만료 30일 전부터 갱신할 수 있고,
> **갱신하면 키가 새로 발급되므로** `.env` 와 GitHub Secrets 을 둘 다 바꿔야 합니다.
> 발급일을 달력에 적어 두세요.

> 모의투자 계정으로도 됩니다(`KIS_ENV=demo`). 다만 모의는 **초당 1건** 제한이고 데이터가
> 실전과 다를 수 있어, 시세만 볼 목적이면 실전을 권합니다.

## 2단계 — 내 PC에서 먼저 한 번 돌려 보기

### 앱키는 절대 남에게 보내지 마세요

앱키·앱시크릿은 **시세 조회뿐 아니라 주문 API도 같은 키로 열립니다.** 비밀번호와 같습니다.
채팅·메일·메신저에 붙여넣지 말고, 이 폴더의 `.env` 에만 두세요
(`.gitignore` 에 들어 있어 GitHub 에는 올라가지 않습니다).

혹시 어딘가에 붙여넣었다면 KIS Developers 에서 **즉시 재발급**하세요. 이전 키는 무효가 됩니다.

### 앱키 넣기 — 메모장 쓰지 마세요

```bat
cd C:\future\optboard
python scripts\setup_env.py
```

묻는 대로 앱키와 앱시크릿을 붙여넣으면 `.env` 를 알아서 만들어 줍니다.
앱시크릿은 입력하는 동안 화면에 찍히지 않습니다.

> **메모장으로 직접 만들지 않기를 권합니다.** 윈도우 메모장은 저장할 때 이름 뒤에 `.txt` 를
> 몰래 붙이고, 확장자가 숨겨져 있으면 그게 보이지도 않습니다. `.env.example` 은 **견본**이라
> 여기에 적으면 읽지 않습니다 — 게다가 이 파일은 GitHub 에 올라갑니다.

### 자가진단

```bat
python scripts\selftest.py
```

7단계를 순서대로 짚어 가며 **어디까지 되는지** 알려 줍니다.
**출력에 앱키는 찍히지 않습니다**(앞 4자리만 별표와 함께). 결과를 그대로 복사해 보내도 안전합니다.

```
▸ 1. 앱키를 읽을 수 있는가          ▸ 5. 행사가별 콜·풋 시세판 (FHPIF05030100)
▸ 2. 접근토큰이 발급되는가          ▸ 6. 종목별 일별 시세 (FHKIF03020100)
▸ 3. 거래소 휴장일 (CTCA0903R)      ▸ 7. 만기일 계산
▸ 4. 옵션 월물 목록 (FHPIO056104C0)
```

### 전부 통과하면 첫 수집

**Mac · Linux**

```bash
python3 scripts/calendar_sync.py   # 거래소 달력
python3 scripts/collect.py         # 오늘치 수집
python3 scripts/build_viewer.py
```

**Windows** (`python3` 대신 `python`)

```bat
python scripts\calendar_sync.py
python scripts\collect.py
python scripts\build_viewer.py
```

`index.html` 을 브라우저로 열어 오늘 날짜 줄이 생겼는지 확인합니다.
오류가 나면 메시지를 그대로 알려 주세요.

| 흔한 오류 | 뜻 |
|---|---|
| `KIS_APPKEY / KIS_APPSECRET 이 없습니다` | `.env` 를 못 찾았거나 값이 비어 있음 |
| `접근토큰 발급 실패: 403` | 앱키·시크릿 오타, 또는 아직 신청이 반영되지 않음 |
| `EGW00133` / 토큰 관련 거절 | 토큰을 너무 자주 발급함. `.token_cache.json` 지우고 1분 뒤 재시도 |
| 응답은 오는데 행사가가 0개 | 휴장일이거나, `config.json` 의 행사가 범위가 너무 좁음 |

**과거 채우기** — 자동화 시작 전 구간은 이걸로 한 번에 메웁니다.

```bash
python3 scripts/master.py                        # 먼저 종목코드부터
python3 scripts/backfill.py --expiry 202609 --from 20260501 --to 20260828
```

`--reset` 을 붙이면 그 월물의 기존 기록을 **지우고 처음부터** 다시 채웁니다.
(잘못된 행사가가 이미 들어갔을 때 씁니다)

> 만기가 지난 월물은 조회되지 않습니다. **월물이 살아 있는 동안** 되메워야 합니다.
> 조회 구간이 길면 100건 제한에 걸리므로 130일씩 자동으로 나눠 받습니다.

## 3단계 — 클라우드 자동 실행 (GitHub)

PC를 켜 두지 않아도 매일 돌게 만드는 단계입니다.

1. GitHub에 새 저장소를 만들고 이 폴더 전체를 올립니다 (`.env` 는 올라가지 않습니다)
2. 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
   - `KIS_APPKEY`
   - `KIS_APPSECRET`
3. 저장소 → **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save
4. **Actions** 탭 → `옵션 시세 수집` → **Run workflow** 로 한 번 수동 실행해 확인

이제 매주 월~금 **한국시간 16:10** 에 자동으로 돌고,
`https://<아이디>.github.io/<저장소이름>/` 이 항상 최신인 내 화면이 됩니다.

> **저장소를 공개(Public)로 두어도 괜찮습니다.** 올라가는 건 공개 시세뿐이고,
> 마킹·메모(`data/marks.json`)는 `.gitignore` 가 막아 내 PC 에만 남습니다.
> 화면도 기본이 손님 모드라 방문자에게는 시세표만 보입니다. 아래 **공개 저장소에서
> 내 것만 감추기** 를 보세요.
> (무료 계정은 비공개 저장소에서 Pages를 쓸 수 없습니다.)

## 4단계 — 화면 쓰는 법

| 하는 일 | 방법 |
|---|---|
| 행사가 바꾸기 | 왼쪽 목록 클릭. 점(●)이 있는 행사가는 마킹·메모가 있다는 뜻 |
| 월물 바꾸기 | 상단 드롭다운 |
| 마킹 | **고가·저가 칸**을 클릭 → 없음 → 네모 → 아랫줄 → 없음 순환 |
| 메모 | 오른쪽 메모 1 / 메모 2 칸에 바로 입력 (자동 저장) |
| 엑셀 | **엑셀 내보내기** — 행사가마다 시트 1개, 마킹은 셀 테두리 색으로, 메모도 함께 |
| 지난 월물 보기 | 월물 드롭다운의 **「지난 월물 (보관)」** 에서 선택 |
| 마킹 영구 보관 | **마킹 보관** → `marks.json` 내려받기 → 내 PC 의 `data/` 폴더에 넣기 (저장소에는 안 올라감) |
| 내 모드로 열기 | 주소 뒤에 **`#me`** 를 붙여 한 번 열기. 해제는 `#guest` |

### 마킹 규칙

색은 고를 필요가 없습니다. **고가 = 빨강, 저가 = 파랑** 으로 고정입니다.
바뀌는 건 모양뿐이고, `자동 연동 마킹` 이 켜져 있으면 한 칸만 눌러도 나머지가 따라옵니다.

네모는 **대각으로 마주 보는 칸**(콜 고가 ↔ 풋 저가 / 콜 저가 ↔ 풋 고가)에 짝으로 들어갑니다.

| 콜 고가를 **네모**로 누르면 | 콜 고가 | 콜 저가 | 풋 고가 | 풋 저가 |
|---|---|---|---|---|
| | 🟥 빨간 네모 | 파란 아랫줄 | 빨간 아랫줄 | 🟦 파란 네모 |

| 콜 고가를 **아랫줄**로 누르면 | 콜 고가 | 콜 저가 | 풋 고가 | 풋 저가 |
|---|---|---|---|---|
| | 빨간 아랫줄 | — | — | 파란 아랫줄 |

한 번 더 누르면 그 날짜의 네 칸이 모두 지워집니다.

예외적인 날은 `자동 연동 마킹` 을 끄면 누른 칸 하나만 바뀝니다.

## 공개 저장소에서 내 것만 감추기

저장소를 Public 으로 두면 **주소를 아는 사람은 누구나 화면을 봅니다.**
시세는 공개 정보라 상관없지만, **마킹과 메모는 매매 판단이 그대로 드러납니다.**
그래서 개인 것은 저장소에 올라가지 않게 갈라 두었습니다.

| | 어디에 | 누가 보나 |
|---|---|---|
| 시세 | `data/{월물}.json` | 누구나 |
| 마킹·메모 | `data/marks.json` | **나만** (`.gitignore` 가 막음) |

### 내 PC 에서는 `내화면.html`

파일을 더블클릭으로 열면 브라우저 보안 규칙 때문에 옆의 `marks.json` 을 읽지 못합니다.
그래서 `build_viewer.py` 가 **마킹·메모를 통째로 심은 개인용 화면**을 따로 만들어 둡니다.

- 내 PC → **`내화면.html`** 을 여세요 (메모 다 보임, `.gitignore` 가 막아 안 올라감)
- 웹 주소 → 공개용. 메모를 웹에서도 보려면 `내화면.html` 의 **마킹 보관 → 복사** 한 내용을
  웹 `#me` 화면의 **마킹 보관 → 붙여넣고 복원** 으로 한 번 옮기면 그 브라우저에 저장됩니다

### 손님 모드 / 내 모드

화면은 **기본이 손님 모드**입니다. 시세표만 보이고 마킹·메모 기능은 아예 나타나지 않습니다.

```
https://아이디.github.io/optboard/        ← 손님 (시세표만)
https://아이디.github.io/optboard/#me     ← 나 (마킹·메모 켜짐)
```

`#me` 로 한 번 열면 **그 브라우저가 기억합니다.** 다음부터는 그냥 주소만 열어도 내 모드입니다.
공용 PC에서 껐다 켜려면 `#guest` 를 붙여 여세요.

> 이건 비밀번호가 아니라 **화면 정리**입니다. 남이 `#me` 로 열어도 저장소에 마킹이 없으니
> 빈 표가 보일 뿐입니다. 다만 **완전한 잠금은 아닙니다** — 정말 아무도 못 보게 하려면
> 저장소를 Private 으로 바꾸고 Pages 를 끄세요.

### 시세 파일에 메모가 섞여 있다면

```bash
python3 scripts/split_memos.py --dry-run   # 무엇이 옮겨질지 먼저 확인
python3 scripts/split_memos.py             # data/marks.json 으로 분리
python3 scripts/build_viewer.py
```

## 만기 알림

KOSPI200 지수옵션의 최종거래일은 **각 결제월의 두 번째 목요일**입니다.
만기가 지나면 그 월물은 API로 다시 받을 수 없으므로, 만기 전에 마킹을 보관하도록 세 군데에서 알립니다.

| 어디서 | 언제 | 무엇을 |
|---|---|---|
| 앱 상단 빨간 배너 | 만기 D-3부터 | 만기일과 남은 날, 「마킹 보관하기」 버튼 |
| 표 제목 옆 배지 | 항상 | `만기 D-12` / `만기 오늘` / `보관` |
| GitHub 이슈 | 만기 D-3부터, 월물당 한 번 | 할 일 체크리스트 (GitHub이 메일로 보냄) |

두 번째 목요일이 **휴장일이면 최종거래일이 직전 개장일로 앞당겨집니다.**
이 판단은 **한국거래소 자신의 달력**으로 합니다 — KIS 오픈API의 `국내휴장일조회(CTCA0903R)` 를
`scripts/calendar_sync.py` 가 받아 `data/calendar.json` 에 캐시해 두고, 만기 계산과 앱 배지가
그 값을 씁니다. 이미 쓰는 앱키를 그대로 쓰므로 **API 키를 새로 받을 필요가 없습니다.**

거래소 달력이라 주말·공휴일뿐 아니라 **근로자의 날(5/1), 연말 폐장일, 임시 휴장일**까지
그대로 들어 있습니다. (KIS 안내에 따라 하루 한 번만 호출하고, 캐시가 5개월 앞을 덮고 있으면
아예 부르지 않습니다.)

달력을 아직 못 받았으면 두 번째 목요일을 그대로 쓰고, 출력에 `달력 미확인` 이라고 표시합니다.

```bash
python3 scripts/calendar_sync.py                    # 거래소 달력 받기
python3 scripts/expiry_notice.py                    # 다음 만기까지 며칠? 근거는?
python3 scripts/expiry_notice.py --date 2026-09-08  # 특정 날짜 기준으로 확인
```

## 설정 (`config.json`)

| 항목 | 뜻 |
|---|---|
| `MONTHS` | `near` 근월물만 / `near2` 근월+차월 (기본) / `all` 전부 |
| `RANGE_MODE` | **`atm`** 지수를 따라 움직임 (기본·권장) / `fixed` 고정 범위 / `all` 받은 것 전부 |
| `ATM_SPAN` | `atm` 모드에서 ATM 위아래로 몇 개씩 담을지. 기본 40 (= 위아래 각 40개) |
| `STRIKE_MIN`, `STRIKE_MAX` | `fixed` 모드에서만 쓰는 **행사가 숫자 자체**. 1000 이면 "행사가 1000 미만은 버림" |
| `PRODUCT` | 화면에 적히는 상품명 |

### 행사가 범위 — 왜 `atm` 인가

`STRIKE_MIN`/`STRIKE_MAX` 는 **행사가 그 숫자**입니다. `1000` 이라고 적으면
"행사가 1000 미만은 버려라"라는 뜻입니다. 그런데 지수는 계속 움직이므로,
한 번 정해 둔 고정 숫자는 몇 달 뒤에 반드시 어긋납니다.

그래서 기본은 `atm` 입니다. 매일 증권사가 알려 주는 **지수 기준가와 ATM 행사가**를 보고
그 위아래로 `ATM_SPAN` 개씩만 담습니다. 지수가 오르면 범위도 따라 올라갑니다.

```bash
python3 scripts/strikes.py            # 증권사가 실제로 어떤 행사가를 주는지 확인
python3 scripts/strikes.py --all      # 거래 중인 월물 전부
```

### 100건 상한과 그 우회

전광판 API(`FHPIF05030100`)는 콜·풋 **각 100건**이 상한인데, **행사가가 높은 쪽부터**
100개를 내줍니다. 지수가 크게 오른 국면에서는 정작 등가 근처가 통째로 잘려 나갑니다.

> 2026-08-28 실측: 지수 약 **1,089** 인데 전광판은 **1350 ~ 1597.5** 만 내려왔습니다.
> 등가 아래가 0개 — 쓸 수 있는 구간이 하나도 없었습니다.

`STRIKE_MIN` 을 낮춰도 소용없습니다. 그건 받아 온 것 중에서 **버리는** 필터일 뿐,
안 온 것을 만들어 내지는 못합니다.

그래서 **거래소 종목코드 마스터**를 직접 받습니다.

```bash
python3 scripts/master.py          # data/optcodes.json 생성 (앱키 불필요)
python3 scripts/master.py --dump   # 파싱이 맞는지 원본 샘플까지 확인
```

여기에는 **모든 행사가의 종목코드**가 들어 있어서, 전광판이 빠뜨린 행사가는
종목별 조회로 따로 받아 옵니다. `collect.py` 와 `backfill.py` 가 알아서 씁니다
(전광판이 준 건 그대로 쓰고, 빠진 것만 개별 조회 — 낭비 없음).

실측(2026-08-28) 결과:

| | 전광판 | 종목마스터 |
|---|---|---|
| 202609 | 100개 (1350 ~ 1597.5) | **506개 (335 ~ 1597.5)** |
| 202610 | 100개 (1347.5 ~ 1595) | **341개 (745 ~ 1595)** |

마스터 파일의 한 줄은 이렇게 생겼습니다.

```
5 | B01609335 | C 202609   335.0 | ATM=2 | 행사가=335.0
↑상품종류      ↑단축코드      ↑한글종목명 (여기에 월물 YYYYMM 이 들어 있음)
```

상품종류 `5`=지수콜, `6`=지수풋만 씁니다. 미니(`D`/`E`)·위클리(`L`/`M`)·
코스닥150(`J`/`K`)은 걸러 냅니다.

### 지수는 어떻게 아는가

전광판 응답의 `nmix_sdpr` 은 지수가 아니었습니다(0.06 같은 값이 옵니다).
대신 **풋-콜 패리티**로 역산합니다.

```
지수 ≈ 행사가 + 콜 종가 - 풋 종가
     = 1350 + 0.41 - 260.7 = 1089.8     (실제 KOSPI200 1088.6)
```

등가에서 멀리 떨어진 행사가만 있어도 정확히 나옵니다. 이 값을 `atm` 모드의 중심으로 씁니다.

## 표시 구간

옵션은 한 월물의 수명 안에서 보는 게 자연스럽습니다. 그래서 화면은 기본으로
**전월물 만기 다음날 ~ 이 월물 만기일**만 보여 줍니다.

표 제목 옆 알약 버튼에 `08/13 → 09/10 · 이전 54일 더 보기` 처럼 뜨고,
누르면 그 월물의 **전체 기간**이 펼쳐집니다. 다시 누르면 접힙니다.
데이터는 언제나 전부 보관되어 있고, 보이는 범위만 달라집니다.
엑셀 내보내기는 **화면에 보이는 구간 그대로** 나갑니다.

## 알아 둘 제약

- **전광판 API는 콜·풋 각각 100건까지** 돌려줍니다. KOSPI200 행사가가 100개를 넘는 국면에서는
  `STRIKE_MIN`/`STRIKE_MAX` 로 관심 범위를 좁혀 두는 편이 안전합니다.
- **만기가 지난 월물은 조회되지 않습니다.** 되메우기는 월물이 살아 있을 때 하세요.
- 전광판 API는 응답이 느린 편이라 **1초에 1회 이내**로 호출하도록 되어 있습니다.
- 마킹·메모는 기본적으로 **브라우저에만** 저장됩니다. 한 달에 한 번쯤 `마킹 보관` 으로
  `marks.json` 을 내려받아 저장소에 넣어 두면, 이후로는 어느 기기에서 열어도 그대로 보이고
  봉인본에도 함께 들어갑니다.
- GitHub Actions 스케줄은 몇 분 늦게 실행될 수 있습니다. 종가는 이미 확정된 뒤라 문제 없습니다.
